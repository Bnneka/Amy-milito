# AMY MILITO COLLECTION

A responsive Next.js website for ladies’ bags and shoes, with home, collection, services and contact pages.

## Run locally

Install Node.js, then run `npm install` and `npm run dev` in this folder. Open http://127.0.0.1:3000.

## Production

Run `npm run build`. The static website is exported to `out/` and can be hosted with a static hosting provider. The Next.js source can also be deployed to Vercel.

## Content

Product photographs are illustrative Unsplash images, labelled as style inspiration. Replace these with the boutique’s actual product photos before presenting items as available stock. Product enquiry buttons open an email draft; no payment or automated order processing is configured. Social links search for the supplied account names because exact profile URLs have not been provided.
